## 实证检验

1. **逐特征 forward-IC 扫描**(train段, 1d标签): 741特征中最大|IC|=0.213, 仅1个>0.2;
   若存在对齐泄漏, 特征会出现0.4+量级的异常IC(见下)。分布正常。
2. **离群特征专项**: `downlimit_capitulation_vs_defense_5m`(|IC| 0.18~0.21)是跌停端
   稀疏事件因子, 非NaN仅2.4%样本; 条件收益: 因子≥中位 → 次日−1.55%, <中位 → +0.02%。
   = 教科书级"跌停延续"效应, 且该子样本84%收盘仍可交易(非封死跌停)。**是真实市场
   效应而非泄漏**。
3. **对齐证伪测试**(该因子): 故意错位+1天(用明日特征预测今日标签)时 |IC| 从0.18跳到
   **0.42** — 证明若管线真有1天错位, 检测器会立刻暴露; 观测值处于正确对齐水平。
4. **可交易性口径**: 原用15:00涨跌停状态过滤, 决策点是14:55 → 抽30天量化不一致率仅
   0.317%, 但仍改为**14:55状态**(无窥视口径), 标签与数据集已重建。
