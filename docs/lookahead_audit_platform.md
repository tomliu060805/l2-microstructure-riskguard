## 一、实证检验(用数据说话,不只看代码)

### ① purge/embargo 边界 —— 逐块验算

取第 10 个 refit 块实测:

```
训练集用到 dates[<1312] = 最晚 2020-05-25
该样本的 5 日标签窗结束于 ≈ 2020-06-01
预测块首日             = 2020-06-02
→ ✅ 零重叠
```

机制:`schedule()` 返回 `(i − EMBARGO_DAYS, block)`,EMBARGO_DAYS = 5 = 最长标签期限。
训练窗内部再切早停集时同样留 5 日 gap(`split_train_es`)。

### ② 全特征 forward-IC 扫描 —— 泄漏的主检测器

train 段、734 个特征、1 日标签:

| 指标 | 值 |
|---|---|
| 最大 \|IC\| | **0.1516**(`downlimit_capitulation_vs_defense_5m\|lh`) |
| \|IC\| > 0.10 | 2 个 |
| \|IC\| > 0.20 | **0 个** |
| \|IC\| > 0.30 | **0 个** |

**判据**:对齐泄漏会产生 \|IC\| > 0.4 量级的离谱值(前身项目做过错位实验,人为错位 1 天
可使 \|IC\| 从 0.18 跳到 0.42)。当前分布正常,**无泄漏迹象**。

排名第一的那个因子是跌停投降类稀疏事件因子,前身项目做过专项核查,
确认是真实的跌停延续效应而非泄漏。

### ③ 标签构造自洽性

`corr(ret_fwd_5d, 连乘 ret_fwd_1d(t..t+4)) = 0.9913`,中位绝对差 0.0007。
→ 5 日标签确实等于 5 个 1 日标签的复利,口径自洽。

### ④ 成分表非事后回填(幸存者偏差)

`load_weights` 逐日提供成分,中证1000 每日恒为 1000 只、跨 11 年无异常波动
→ 是逐日快照,不是"用最终成分表回填历史"。

## 三、本次融合新引入改动的专项审计

### 市值重建(2026-08-13 新增)

**背景**:`${IDXML_MCAP_ROOT}` 止于 2025-07-17,缺失期用
「最后已知流通股本 × 当日收盘价」重建。

**风险点**:用了**当日收盘价**,而决策点是 14:55 —— 收盘价严格说未知。

**结论:安全**。因为 `build_styles` 对市值统一做了 `shift(1)`:

```python
mc["mcap_lag"] = mc.groupby("symbol")["mcap"].shift(1)
mc["size"] = np.log(mc["mcap_lag"].clip(lower=1e-6))
```

实际进入模型的是 **t−1 日的收盘市值**,决策时已完全已知。✅

**另一重保险**:该重建只影响 `size` 这一个风格因子,且只用于中性化回归取残差,
对量纲不敏感。拆分对照(实测市值段 vs 重建段)也已证明不抬高结果 —— 见成果总览第十二节。

### 测试段解锁

解锁只通过环境变量 `IDXML_TEST_UNLOCK=1`,`assert_dev_dates` 在未解锁时直接抛异常。
测试段预测由 `lgbm_y5d_rank_oos_WITHTEST` 单独产出,**不覆盖原验证段预测文件**,
两套结果可并存对照。✅

## 四、发现的问题

### ⚠️ 文档与代码不一致(已发现,待修)

`shared/build_labels.py` 的**文档字符串**写着:

> 可交易性: limit_status(**15:00**) != 0 或 paused(15:00) != 0 → tradable=0

但**实际代码**取的是 14:55:

```python
lim = lim[lim["datetime"].dt.time == pd.Timestamp("2000-01-01 14:55:00").time()]
```

**代码是对的(14:55 才是决策时点),文档字符串是旧版残留。**
不影响任何结果,但会误导读代码的人 —— 应修正文档。

## 五、已知且接受的近似(报告时需注明)

1. **成本为线性费率**,未建模冲击成本;A2 已用 L1 五档快照实测半价差校准,
   但冲击仍用通用平方根律参数(c=1、σ=2%),未用本项目数据校准;
2. **交易假设**:14:55 出信号、15:00 收盘价成交。实盘存在滑点与竞价不确定性;
3. **不可交易股躲不掉**:封跌停时无法卖出,实测占比 csi1000 约 1.3%、gz2000 约 2.2%;
4. **国证2000 为代理域**(市值秩 1001-3000,T−1 定域),非官方指数成分;
5. **验证段被多轮分析反复使用**(A1/A2/配置扫描/稳健性),乐观偏差累积 ——
   这正是保留测试段的原因,测试段已于 2026-08 一次性开封。
