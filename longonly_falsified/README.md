# 项目A — 纯多头选股（四指数域）

**目标**：在沪深300 / 中证500 / 中证1000 / 国证2000代理 四个指数域上，用 L2 微观结构因子
预测个股未来 5 日截面收益，选出会跑赢的票，作为指增产品的 **alpha 层**。

**与项目B 的分工**：本项目关心截面**上尾**（谁会涨），项目B 关心**下尾**（谁会跌）。
两者独立训练、独立结论，可叠加成完整指增产品（见 [../对接文档.md](../对接文档.md) §3.3）。

---

## 1. 方法

### 1.1 特征

247 个 Level-2 高频微观结构因子（5 分钟频），每因子做 3 个日内聚合：

| 聚合 | 含义 |
|---|---|
| `\|mean` | 当日 09:30–14:55 全日均值 |
| `\|std` | 当日日内波动（因子自身的截面外波动） |
| `\|lh` | 尾盘 14:00–14:55 均值 |

合计 **741 维 + coverage**（有效 bar 覆盖率）。**只用到 14:55，剔除 15:00 那根 bar**——
信号在收盘前 5 分钟已知，可按收盘竞价成交；标签从 15:00 起算，特征严格先于标签。

### 1.2 标签与目标

- 标签：`ret_fwd_5d` = 未来 5 日收益（15:00 起算，复权口径）
- 训练目标：`y5d_rank` = 该指数当日成分内的横截面秩，中心化到 `[-0.5, +0.5]`
- 对照目标：`y1d_rank`（1 日）

### 1.3 模型与评估协议

| 项 | 设定 |
|---|---|
| 模型 | IC加权线性（top60因子）/ LightGBM / XGBoost，各 3 种子平均 |
| 重训 | 每 **63 个交易日** refit，扩张窗，最小训练窗 750 日 |
| Purge | 训练集与预测块之间留 **5 日 embargo**（= 最长标签期限），零重叠 |
| 早停 | 训练窗末 63 天做早停验证，与拟合段之间再留 5 日 embargo |
| 评估 | 严格 walk-forward 样本外；验证段 2022-07-01 ~ 2024-06-28 |
| 组合 | 十分组 + `tranche5`（每日轮换 1/5 仓位，降换手） |
| 成本 | 双边 0 / 10 / 20 / 30 bp 四档敏感性 |

### 1.4 为什么用这套模型而不是别的

继承自前身项目（中证500 单域）的已验证结论，**不重复试错**：

- **GBDT 家族同质**：LGBM 与 XGB 预测秩相关 0.963，集成零提升 → 瓶颈在特征不在模型
- **GBDT > 神经网络**：MLP 净20bp Sharpe 1.61、GRU 1.41，均低于 LGBM 1.81
- **时序建模无增量**：GRU 用 5 日序列 ≈ 当日截面聚合（RankIC 0.089 vs 0.089）
- **换手是生死线**：日频全调仓在 20bp 下必亏，必须用 tranche/平滑控制换手

## 2. 运行

```bash
cd code
export IDXML_DS_ROOT=<repo>/data     # 本地副本，绕开共享盘 I/O 饱和

# 训练（每个指数独立）
/usr/bin/python3 train_baselines.py --index csi1000 --model lgbm   --seeds 3 --threads 40
/usr/bin/python3 train_baselines.py --index csi1000 --model linear                 # 基线对照
/usr/bin/python3 train_baselines.py --index csi1000 --model xgb    --seeds 3       # 同质性验证

# 回测
/usr/bin/python3 backtest.py --index csi1000 --pred lgbm_y5d_rank --style tranche5 --side long
/usr/bin/python3 backtest.py --index csi1000 --pred lgbm_y5d_rank --style tranche5 --side ls

# 汇总与归因
/usr/bin/python3 summarize.py         --index csi1000
/usr/bin/python3 analyze_importance.py --index csi1000
```

四个域依次跑：`for ix in hs300 csi500 csi1000 gz2000; do ... --index $ix ...; done`

## 3. 必须报告的指标（项目纪律）

任何回测结果都必须带**单笔指标全套**：

> 触发数 / 胜率 / 单笔均 / 盈亏比 / 盈利因子

外加：RankIC、日ICIR、IC正天占比、D1与D10年化、日换手、
毛Sharpe、净20bp Sharpe、净30bp Sharpe、最大回撤、TE（多头口径）。

**分年一致性**：分年 RankIC 的 t 值与符号必须一致；分年不同号或 |t|<2 视为无效。

## 4. 已知边界与注意事项

1. **小盘域用重构的 gz2000**（T-1 市值秩 1001–3000）而非中证2000——后者 2023 年才发布、
   之前成分为回溯重构。重构域与官方国证2000 日收益相关 0.9788，但年化差 +4.34%，
   **基准用重构域自身市值加权收益**（详见 [../README.md](../README.md)）。
   2015-16 成分不满 2000，该域结论需配合训练窗敏感性对照解读。

2. **基准口径**：多头超额的基准用**指数权重**（非等权）。
   前身项目用的是成分股等权基准，数字不可直接对比。

3. **执行假设**：所有回测假定 14:55 决策、收盘竞价成交。
   若实盘只能次日开盘执行，结论作废需重跑。

4. **测试段未开封**：2024-07-01 起被硬封锁，上线前需一次性开封验证，
   且建议事先书面固定通过门槛。

## 5. 结果（验证段 2022-07-01~2024-06-28，484 天）

### 5.1 多空口径（信号纯度）

| 域 | RankIC | IC正天 | D1 年化 | D10 年化 | 毛Sharpe | **净20bp Sharpe** | 净30bp | MDD |
|---|---|---|---|---|---|---|---|---|
| 沪深300 | 0.0857 | 71% | −59.7% | +25.6% | 3.11 | 1.69 | 0.99 | 11.2% |
| 中证500 | 0.0927 | 71% | −58.0% | +30.3% | 2.99 | 1.82 | 1.24 | 12.3% |
| 中证1000 | 0.0931 | 73% | −88.3% | +24.3% | 4.21 | 2.67 | 1.90 | 13.7% |
| **国证2000代理** | **0.1107** | **82%** | **−121.9%** | **+32.5%** | **5.24** | **3.66** | **2.86** | 10.1% |

单笔指标（净20bp）：胜率 55.8/51.0/57.0/59.3%，盈利因子 1.32/1.35/1.56/1.81。

### 5.2 多头超额口径（指增产品实际口径，基准=指数权重）

| 域 | 超额毛 | 净20bp | 净30bp | **IR(净20)** | 胜率 | MDD |
|---|---|---|---|---|---|---|
| **沪深300** | +20.25% | **+10.30%** | +5.33% | **1.25** | 52.7% | 7.97% |
| **中证500** | +18.50% | **+9.67%** | +5.26% | **1.22** | 49.2% | 6.70% |
| 中证1000 | +14.95% | +3.01% | **−2.97%** | 0.43 | 50.8% | 8.02% |
| 国证2000代理 | +14.45% | +2.38% | **−3.65%** | 0.35 | 47.7% | 8.36% |

### 5.3 核心结论：两个口径的规律完全相反

**多空口径小盘碾压大盘（3.66 vs 1.69），纯多头却倒过来（IR 0.35 vs 1.25）**，
小盘域净30bp 甚至转负。根因：小盘域信号绝大部分在**空头端**（下尾/上尾强度比 3.44×），
纯多头吃不到。

**→ 本项目（纯多头选股）的适用域是沪深300 / 中证500；
中证1000 / 国证2000 应该用[项目B（规避）](../riskguard/)**——
同一 gz2000 域，纯多头 IR 0.35 vs 规避 IR 5.56，差 16 倍。

### 5.4 gz2000 训练窗敏感性（已通过）

| 训练窗 | RankIC | 净20bp Sharpe | MDD |
|---|---|---|---|
| 全历史(2015+) | 0.1107 | 3.66 | 10.1% |
| 2017+(域完整) | 0.1118 | 3.61 | 11.3% |
| 2021+ | 0.0880 | 3.57 | 6.4% |

三档差异仅 2.5% → 结论不依赖 2015-16 成分不满的样本，**域漂移风险排除**。
